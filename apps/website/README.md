# Grocerra website

Public landing page for grocerra.com (Next.js, static).

- Run locally: `npm install && npm run dev`
- Deploys: every push to `main` deploys to production at https://grocerra.com through Vercel (project `grocerra-website`, root directory `apps/website`). Other branches and PRs get a preview link.
- Edit the page in `app/page.tsx` and styles in `app/globals.css`.
